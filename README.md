# Портфолио — разработка на MQL5 и Python

Привет! Я разрабатываю торговых роботов (советников EA), индикаторы и
автоматизацию для MetaTrader 5, а также Python-скрипты для сбора и анализа
данных. Специализация: **MQL5, Python, анализ данных, машинное обучение (ONNX)**.

## Что умею

- Написание советников (Expert Advisors) под заказ на MQL5
- Индикаторы и скрипты для MetaTrader 5
- Доработка и исправление чужих советников
- Python: сбор данных (RSS/API/парсинг), автоматизация, отчёты
- Машинное обучение: Python (PyTorch) → ONNX → MetaTrader 5
