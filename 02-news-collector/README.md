# Сборщик экономических новостей и календаря (Python)

Автоматический сбор экономического календаря и новостей с валидацией источников
и хранением в SQLite/JSON.

## Что делает

- Собирает экономический календарь (события, время, страна, важность).
- Собирает новости из RSS/API-источников.
- Валидирует источники (страна, доступность, ограничения).
- Хранит в SQLite + JSON, ведёт журнал (journal.jsonl).
- Формирует сравнение нового выпуска с предыдущими (conjunction/divergence).

## Файлы

- `collector.py` — точка входа сбора.
- `pipeline.py` — основной конвейер обработки.
- `sources.json` — конфигурация источников с фильтром по стране.

## Стек

Python · RSS · JSON · SQLite · стандартная библиотека
