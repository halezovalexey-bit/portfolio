# Недельный анализ рынка и счёта (Python)

Автоматический недельный отчёт: снимает бары через API MetaTrader 5, считает
движение рынка и сводит состояние торгового счёта.

## Файлы

- `pull_market.py` — выгрузка H1/D1 баров через MetaTrader5 API.
- `analyze_week.py` — сводка рынка: гэп понедельника, недельное движение, пробой
  экстремумов, журнал советника.
- `weekly_report.py` — итоговый отчёт: счёт, рынок, журнал, краткое резюме.

## Стек

Python · MetaTrader5 API · JSON
