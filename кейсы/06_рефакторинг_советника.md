# Кейс 6: рефакторинг чужого советника (GOLD_ORB → v2)

**Стек:** MQL5, рефакторинг, офлайн-компиляция MetaEditor

## Что сделано

Взял чужой учебный советник с mql5.com (Playground «Practice1», 2021) — Opening Range
Breakout на XAUUSD H1 — и переделал его в чистый self-contained советник. Стратегию
сохранил верной, код вычистил до одного файла.

## Чем сложно

- **Отделить стратегию от мусора.** Оригинал тянул ~30 библиотек (ALGLIB, Fuzzy, Stat,
  виртуальная торговля), из которых торговая логика использовала малую часть; SMA-фильтр
  считался, но нигде не применялся (мёртвый код).
- **Чужой магик.** Оригинал торговал на дефолтном магике CTrade (0) и на любом символе —
  при переносе назначен собственный magic, символ замкнут на XAUUSD.
- **Захардкоженные параметры → входные.** Трейлинг (700/100/10) был зашит в код — стал
  входным параметром.
- **Устаревшие вызовы** `iClose/iHigh/iLow` заменены на `CopyRates`/`CopyBuffer`.

## Результат

357 строк одним файлом (против исходных ~10 тыс. знаков + include-дерево), компиляция
0 ошибок / 0 предупреждений, готовый пресет. Запущен на демо для форвард-теста.

Дифф «было/стало» (магик, символ, зашитые параметры); фрагмент кода до/после рефакторинга.
