# Кейс 5: автоматический недельный анализ рынка

**Стек:** Python, MetaTrader5 API, отчёт в Markdown

## Что сделано

Автоматический еженедельный отчёт по рынку: выгрузка данных из MT5 (`pull_market.py`) →
анализ недели (`analyze_week.py`) → генерация отчёта (`weekly_report.py`). Полный цикл без рук.

## Чем сложно

- **Полная автоматизация** — данные → анализ → готовый Markdown-отчёт, одна команда.
- **Чтение демо-счёта только на чтение** — подключаюсь к терминалу, не вмешиваясь в позиции
  и не трогая открытые сделки.
- **Недельный ритуал** — открытие новой торговой недели начинается с анализа прошлой:
  что сработало, что нет, какие уровни в силе.

## Результат

Рабочий генератор: пример готового отчёта `WEEKLY_2026-10-02.md` (тренды, уровни, итоги
недели) лежит рядом с кодом.
