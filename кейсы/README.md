## О себе

Разработчик MQL5 и Python. Пишу советники и индикаторы для MetaTrader 5 по ТЗ, прогоняю
торговые идеи через честный бэктест (walk-forward, издержки, базовые линии), подключаю
ML-модели (Python → ONNX → MT5). Не обещаю прибыль — честно показываю реальные цифры.
