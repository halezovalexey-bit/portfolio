# Кейс 2: конвейер Python → ONNX → советник MT5 с честной проверкой

**Стек:** Python (pandas, scikit-learn, PyTorch, ONNX), MQL5, MetaTrader5 API

## Что сделано

Полный конвейер машинного обучения для торговых советников: выгрузка истории → 22 признака
→ обучение (градиентный бустинг + LSTM на GPU) → экспорт в ONNX → генерация советника MQL5
(те же 22 признака, вход через `OnnxRun`) → автоматический прогон в тестере MT5 без мышки.

## Чем сложно

- **Честность методики** — walk-forward (обучение 2 года → тест 3 месяца, 40 окон), embargo
  (последние строки окна выбрасываются, чтобы метка не «заглядывала» вперёд), издержки
  (спред + комиссия) вычтены из каждой сделки.
- **Базовые линии** — «всегда лонг» и «всегда шорт» считаются на тех же точках входа: если
  модель их не обгоняет, она не даёт преимущества.
- **Нормировка вшита внутрь ONNX-графа** — среднее и сигма посчитаны на обучении и живут
  внутри модели, поэтому Python и MQL5 физически не могут рассогласоваться.
- **22 признака перенесены в MQL5 1:1** — те же формулы, `ddof=1` для стандартных отклонений,
  RSI через экспоненциальное сглаживание `alpha=1/14`, как в pandas.

## Результат (честно)

Конвейер полностью рабочий (Python → ONNX → советник → тестер), но на текущем наборе
признаков торгуемого преимущества нет: точность направления 0.49–0.52 (на грани случайности),
AUC 0.50–0.52. Лучшие комбинации едва обгоняют базовые линии (профит-фактор 1.03–1.06), а на
золоте (XAUUSD M15, 276 тыс. баров, 2015–2026) модель не бьёт простое удержание лонга.

Ценность кейса — не «прибыльный робот», а **умение честно измерять**: показываю реальные
цифры, а не красивую кривую, подогнанную под историю. Поверх конвейера сделан продукт:
`run.py --symbol XAUUSD --tf M15` (любой символ/ТФ за один вызов) и `make_client_report.py`
(автоматический честный отчёт клиенту).

Продолжение — форвард-тест вживую: модель из out-of-sample сборки (`_deploy`, обучена до
отсечки) поднята на демо-счёт в реальном времени. ONNX грузится, inference на CPU, вход при
вероятности ≥0.55 (long) / ≤0.45 (short), фикс 0.1 лота. Это то же правило, что в тестере —
обучение на прошлом, прогноз на будущем, — только на живых барах.
