# Советник HermesForward V5 (MQL5)

Торговый робот для MetaTrader 5, ~1100 строк. Написан с упором на **безопасность**:
это демонстрация промышленной архитектуры советника, а не «прибыльная стратегия».

## Что реализовано

- **Механизм 1 — гэп-фейд выходных:** вход против разрыва пятницы, тейк-профит по
  пятничному закрытию, стоп-лосс = 1.0×|гэп|, таймаут 168 ч, ATR-фильтр качества
  (пропуск, если волатильность до разрыва ниже порога).
- **Механизм 2 — пробой 55-дневного экстремума:** закрытие дня за 55-дневный
  максимум → buy, за минимум → sell; стоп = 1.5×ATR(D1), удержание до 60 дней.
- **Новостной фильтр (fail-closed):** разбор риск-снапшота с проверкой целостности
  SHA256; при некорректном или отсутствующем снапшоте новые входы блокируются.
- **Система защиты:** только демо-счёт, проверка логина, магик-номер, риск 0.25% на
  сделку, лимит лотов, бюджет сделок на год, журнал сделок (raw deal ledger),
  сторожевые ограничения просадки.

## Технические детали

- Язык: MQL5. Архитектура разделена: механизмы входа, защита, журнал — отдельно.
- Все защитные условия **fail-closed** — при несоответствии торговлю блокируют,
  а не пропускают. Это ключевой принцип защиты депозита.
- Код размечен как кандидат для демо-проверки, не для реальной торговли.

## Зачем это в портфолио

Показывает умение писать сложных советников с защитой от потери депозита: проверка
счёта, лимиты риска, бюджеты, журналирование, fail-closed логика. Тот же подход
применяю к советникам под заказ.
